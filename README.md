# Transparent Agent Activity Timeline: proposal prototype

Design proposal for Ziki: a Transparent Agent Activity Timeline that shows what an AI agent is doing, lets people inspect evidence and answer its questions, and separates what the agent reported from what Ziki verified. Clickable prototype with sample data.

**Status: draft for community feedback. Not approved, not implemented.** It was made without access to Ziki's code, docs or design files, so the visuals are stand-ins and every name and figure is sample data.

## View it

Open `index.html` in a browser, or use the hosted version once GitHub Pages is switched on for this repository.

## What's inside

- `index.html`: overview and entry point
- `open.html`, `evidence.html`, `question.html`, `response.html`, `complete.html`: the five-screen walkthrough
- `states.html`: every status, trust label and question state
- `proposal.html`: problem, solution, edge cases and open questions for the community

Plain static HTML with no build step.
